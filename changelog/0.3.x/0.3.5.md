# 0.3.5 — 2026-08-22

## Changed

- **MCP protocol surface.** Tools now advertise JSON Schema 2020-12, declare error envelopes in `outputSchema`, and support the current MCP protocol revision.
- **Tool inputs.** Undeclared root input keys are rejected before the handler runs; clients must remove misspelled or unsupported arguments.
- **Runtime and test tooling.** Docker stages and `packageManager` use Bun 1.4.0; the test suite adds smoke, contract, fuzz, coverage, and test typecheck coverage.
- **Community health.** Adds contributing and conduct guidance, and routes private vulnerability reports to `security@caseyjhand.com`.
