# 0.3.1 — 2026-07-30

## Added

- **`openmeteo_get_forecast` gains the shared spillover pattern.** New `canvas_id` input; additive `record_count`, `truncated`, `canvas_id`, `table_name` output. A wide window (`past_days` up to 92 alongside `forecast_days` up to 16) spills to DataCanvas when enabled, or takes the canvas-less bounded preview when it is not — the same tradeoff already accepted by `openmeteo_get_historical`, `openmeteo_get_ensemble`, `openmeteo_get_flood`, and `openmeteo_get_climate`. Measured on a 92-day, 12-variable Seattle pull, the response drops from 1,509,388 bytes to 164,064 with canvas disabled (164,068 with `duckdb`). Forecast is now the fifth staging tool: `openmeteo_dataframe_query`/`openmeteo_dataframe_describe` descriptions, `src/index.ts` server instructions, `canvas-accessor.ts`, README, `docs/design.md`, `server.json`, `manifest.json`, `.env.example`, and `.codex-plugin/plugin.json` updated to match. ([#29](https://github.com/cyanheads/open-meteo-mcp-server/issues/29))

## Fixed

- **Spill-capable tools no longer report `truncated: false` on an unbounded payload when DataCanvas is disabled.** `openmeteo_get_historical`, `openmeteo_get_ensemble`, `openmeteo_get_flood`, and `openmeteo_get_climate` measured the inline budget but only acted on it inside an `if (canvas)` branch — with `CANVAS_PROVIDER_TYPE` unset (the default), an over-budget result fell through to a full inline return with no cap. Three new shared helpers in `spill-utils.ts`: `boundedPreview()` bounds the response to the same `PREVIEW_CHARS` budget `spillover()` drains and sets `truncated: true`, skipping any leading all-null rows so the preview always carries data; `splitByCadence()` splits concatenated hourly/daily records by timestamp shape; `noCanvasNotice()` renders the `format()` text explaining there's no `canvas_id` and how to reach the rest. `record_count` keeps reporting the full upstream total on this path, not the preview length. ([#28](https://github.com/cyanheads/open-meteo-mcp-server/issues/28))
- **`docs/design.md`'s Tools table listed only 6 of 11 tools.** Added the five missing rows: `openmeteo_get_ensemble`, `openmeteo_get_flood`, `openmeteo_get_climate`, `openmeteo_dataframe_describe`, `openmeteo_dataframe_query`.
