# 0.3.11 — 2026-09-21

## Added

- **`.github/workflows/codeql.yml`** — the one GitHub Actions workflow this project carries; runs only while the repo's CodeQL default setup is off.

## Changed

- **`canvas_id` inputs on the nine canvas-aware tools validate against the minted token shape** `^[A-Za-z0-9_-]{10}$` at argument validation ([cyanheads/mcp-ts-core#327](https://github.com/cyanheads/mcp-ts-core/issues/327)) — a malformed id is rejected as `invalid_arguments` before any upstream request or canvas lookup. Required on `openmeteo_dataframe_describe`/`openmeteo_dataframe_query`, optional elsewhere; output `canvas_id` fields stay plain strings.
- **Tool error text closes with `(reason <reason>)`**, plus `· not retryable` / `· retryable` when the error states it ([cyanheads/mcp-ts-core#458](https://github.com/cyanheads/mcp-ts-core/issues/458)); `structuredContent` is unchanged.
- **Argument rejections carry `data.reason: "invalid_arguments"` and a synthesized recovery hint** ([cyanheads/mcp-ts-core#445](https://github.com/cyanheads/mcp-ts-core/issues/445)); an unknown key's hint names the keys the tool accepts.
- **An argument key sent in another case style (e.g. `hourlyVariables`) resolves to the declared key**, and a fixed list of client-added root keys is dropped ([cyanheads/mcp-ts-core#452](https://github.com/cyanheads/mcp-ts-core/issues/452), [#453](https://github.com/cyanheads/mcp-ts-core/issues/453)). Any other undeclared key is still rejected; `inputSchema` is unchanged.
- **Each declared `errors[]` `when` clause's rendered description ends with a period** ([cyanheads/mcp-ts-core#389](https://github.com/cyanheads/mcp-ts-core/issues/389)) — rendering-only.
- Framework skills, `lint:mcp`'s config knob, and the GH issue forms synced to mcp-ts-core 0.13.6.

## Fixed

- **`openmeteo_dataframe_query` reports a DuckDB conversion error as a validation error** — `sql_execution_error` with a recovery hint, instead of a database error ([cyanheads/mcp-ts-core#451](https://github.com/cyanheads/mcp-ts-core/issues/451)).
