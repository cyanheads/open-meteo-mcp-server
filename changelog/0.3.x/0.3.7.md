# 0.3.7 — 2026-09-09

## Added

- **`response-notice.ts`** composes the `notice` field from the unserved-variable warning, coverage-gap notices, and the canvas pointer into one string — `ctx.enrich.notice()` is last-write-wins, so a second call used to silently drop the first (#40, #44).
- **Coverage-gap notices** (#40). All seven weather tools flag a recognized variable whose requested window falls outside a dataset's coverage — real units, null values — naming the variables and either that the window is empty or the first/last timestamp with data.
- **Canvas pointer names both dataframe tools, `describe` first** (#44). The `notice`, `format()` line, and `canvas_id`/`table_name` descriptions on every spill-capable tool now name `openmeteo_dataframe_describe` before `openmeteo_dataframe_query` — the staged table's columns vary per request, so there's no valid SQL before the schema is read.

## Fixed

- **`INLINE_CHARS` now bounds the whole response, not just preview rows** (#41). Unit maps, scalar fields, and the notice count against the ceiling on both `structuredContent` and `content[0].text` — every spill-capable tool returns fewer preview rows at the same input. Unit maps are trimmed only below an 8,000-character row floor, with a notice naming the count.
- **Spilled responses can no longer report `truncated: false`** (#41). The full record set is always staged once a response is ruled oversized, instead of asking `spillover()` to re-decide against its own looser measure.
- **`openmeteo_get_air_quality`, `openmeteo_get_flood`, and `openmeteo_get_climate` take their canvas-path preview from `boundedPreview()`** (#41), so the leading-all-null-row skip applies there too.
- **CAMS air-quality archive start corrected to August 2022** (#40), replacing "at least 2022-10-01," across the tool description, `start_date` input, README, and server instructions; `us_aqi` starts a day later than the pollutant series.
