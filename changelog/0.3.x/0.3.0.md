# 0.3.0 — 2026-07-30

## Changed

- **`openmeteo_geocode` renamed to `openmeteo_search_locations`.** Input, output, error contract, and runtime behavior are unchanged; no compatibility alias — clients calling the old name must switch. Implementation moved to `search-locations.tool.ts` (exported symbol `openmeteoSearchLocationsTool`), and every cross-reference updated: server instructions and the `latitude`/`timezone` descriptions on the six weather tools, `README.md`, `docs/design.md`, `docs/idea.md`, `CLAUDE.md`/`AGENTS.md`, and the Codex plugin's long description. ([#27](https://github.com/cyanheads/open-meteo-mcp-server/issues/27))
- **`.mcpb` bundle strips platform-specific DuckDB natives.** `scripts/clean-mcpb.ts` now removes `@duckdb/node-bindings-*` entries alongside the existing agent-doc strip, taking the published bundle from 42.9 MB — over the 25 MB cap registries enforce, and locked to whichever platform packed it — to 5.86 MB and portable. `@duckdb/node-api` stays an optional peer loaded lazily, so a canvas tool without it reports an actionable install hint and every other tool is unaffected. `scripts/lint-packaging.ts` gained a matching post-bundle check, and `tests/scripts/packaging-entry-regex-sync.test.ts` pins the two scripts' strip patterns identical.
- **Dependencies:**
  - `@cyanheads/mcp-ts-core` `^0.10.14` → `^0.11.0`
  - `@duckdb/node-api` `^1.5.4-r.1` → `^1.5.5-r.1`
  - `@biomejs/biome` `^2.5.3` → `^2.5.5` (dev)
  - `@types/node` `^26.1.1` → `^26.1.2` (dev)
  - `tsc-alias` `^1.9.0` → `^1.9.1` (dev)
- **Framework sync.** Skills re-synced to `mcp-ts-core` 0.11.0 in `skills/` and `.claude/skills/`; `CLAUDE.md`/`AGENTS.md` adopt the current framework template (`ctx.enrich`/`ctx.content`, `ctx.recoveryFor()`, `z.stringbool()` guidance, `createApp()` identity fields). `scripts/devcheck.ts`'s outdated-package gate now excludes peer-dependency rows (a peer range declares a floor, not a version to track) and treats any `Update === Current` row as satisfied rather than special-casing `minimumReleaseAge` holds. `scripts/check-dependency-specifiers.ts` extends its floating-specifier check to `overrides`. `.gitignore`'s `data/` entry is anchored to `/data/` so it only matches the repo root. The OTel `bun add` step in `Dockerfile` now passes `--omit=dev --ignore-scripts`.

## Added

- **`tests/tools/tool-surface.test.ts`** pins the advertised tool surface: 11 tools, every name matching `openmeteo_<verb>_<object>`, `openmeteo_search_locations` present, `openmeteo_geocode` absent.
