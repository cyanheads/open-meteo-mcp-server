# 0.4.1 — 2026-10-12

## Added

- **`rate_limited` error reason** on all nine upstream tools, carrying a recovery hint (#56). A request that exceeds the per-address concurrency cap ("Too many concurrent requests") is retried, and surfaces as `rate_limited` with `retryAttempts` only if the retries run out (#75).
- **`openmeteo_search_locations` `effective_language`** — names the language a native-script query was retried in when that retry supplied the results (#69).
- **`openmeteo_dataframe_query` `count_error` and `row_too_large`** — `count_error` marks `row_count` as a lower bound when counting fails or exceeds 5 seconds (#72); `row_too_large` rejects a first row that cannot fit the inline ceiling (#65).
- **Free-tier limits in the server instructions** — fewer than 600 calls a minute, 5,000 an hour, and 10,000 a day per IP address, and how request size counts against them (#54).

## Changed

- **`openmeteo_dataframe_query` preview** holds up to 100 rows and stops before the 80,000-character inline ceiling; `row_count` is the exact total, with a notice giving the `OFFSET` to continue at (#65, #72).
- **`openmeteo_get_ensemble`** — an omitted or blank `models` selects `ecmwf_ifs025_ensemble`, and `model` is always present in the output (#73). `forecast_days` reaches 35; past a model's horizon its columns are null and the notice names where its data ends (#68). Size-reduction hints name lighter global models by member count (#74).
- **Date inputs** on the historical, marine, air-quality, flood, and climate tools must be real calendar dates (#70); `2024-02-30` is rejected instead of answering for 2024-03-01.
- **Variable and model names** on the seven weather tools are trimmed and blank entries dropped; a list left with no names fails as `no_variables_requested` (#62).
- **Null `current` values** under a real unit, and null series from a location a dataset does not cover (pollen outside Europe, waves at a land point), are named in the `notice` (#63).
- **`current.interval`** is described as the aggregation interval in seconds, not an update cadence (#67).
- **No-canvas previews** render a one-line pointer in `format()`; the full disclosure stays in `notice` (#55).
- **`openmeteo_get_flood`** describes `river_discharge` as the daily value and the `_mean`, `_median`, `_min`, `_max`, `_p25`, `_p75` statistics as ensemble statistics that repeat it in reanalysis mode (#64).
- **Request URLs** no longer appear in error data or client-visible logs (#59).
- Docs: `docs/design.md` Tool Detail matches the shipped schemas and error contracts (#57); the historical archive default is described as Best Match (#58).

## Fixed

- **`openmeteo_get_elevation`** returns `elevation_m: null` for a point the DEM has no value for, where an upstream `nan` failed the whole batch (#61). Longitude 180 is sent as -180.
- **`openmeteo_dataframe_query` table cells** escape newlines, tabs, backslashes, quotes, and edge or invisible spaces, so each row renders as one line (#66).
